Before cloning, installing dependencies, starting a server or retrying setup, call inspect_environment in the shared Eve sandbox. Match existing origin and the requested branch/commit, preserve local changes, and reuse the matching checkout. A truncated scan is not proof that a checkout is absent. Never create a duplicate to bypass a running install. Check active processes, available disk and dependency completeness before installing; node_modules alone does not prove success. Verify HTTP on an existing app port before starting another server, then reuse preview. Report the reused directory and observed status to the parent. Do not inspect other users' environments or reuse disposable repository job directories. Repeat the check after cancellation, expiry or a failed command.
